# ArenaPulse — портфолио киберспортсмена

Платформа, где **игрок сам ведёт профиль и статистику** — без интеграции с CS2, Dota 2 и другими клиентами. Подходит для диплома: все функции работают через ручной ввод.

## Концепция

| Раздел | Что делает игрок |
|--------|------------------|
| **Мой профиль** | Био, роль, LFT, аватар, ссылки Steam/FACEIT |
| **Дисциплины** | Вручную указывает MR и W/L по игре |
| **Журнал матчей** | Добавляет K/D/A, счёт, изменение MR |
| **Pulse DNA** | Слайдеры стиля или авторасчёт из матчей |
| **Достижения** | Турниры, топы, награды |
| **Trust Index** | Растёт от заполненности профиля |

## Запуск

```powershell
cd C:\Users\tkach\projects\cybersport-arena

```

## Демо-сценарий на защите

1. Войти как `pro@arena.dev`
2. Открыть **Мой профиль** → добавить дисциплину и матч
3. Показать рост **Trust Index** и **заполненность**
4. Открыть **публичную страницу** игрока и **рейтинг**
